The funniest one-line warning label for a time machine (95 characters):

> WARNING: Meeting yourself voids the warranty. If you already have, report yourself to yourself.

`main.py` (pure Python standard library) writes the label to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and re-reads it to verify the bytes. Deterministic: two runs produce byte-identical output.

## Run it

```sh
python3 main.py
```
